# 心愿按最近活动排序

用户确认：参与一次转盘的所有勾选项都算最近使用，不只中奖项。

展示按最近新增或参与转盘的先后倒序。单纯勾选、取消、编辑和兑现不改变排序；同一轮参与项沿用轮前显示顺序，避免任意跳动。各分类和搜索在排序结果上过滤。

持久化 recentOrder 作为递增活动序号，无需依赖系统时钟。新增项取得下一个序号，每次抽奖同批参与项更新为同一个新序号。旧项目按原始数组位置推断新增先后，兼容既有本机数据。编辑保留序号；幂等抽奖重试不重复更新。内部 items 数组与抽奖快照不重排，转盘扇区和结果定位保持一致。

新增成功与转盘结束后将清单滚至顶部。验证新增倒序、整轮参与项置前、同轮稳定、勾选/编辑不跳位、刷新持久化、幂等及抽样快照不变。
