# 心愿补充与分类图标

用户明确指定新增 7 份吃喝玩乐心愿，以及笑脸、动物、食物、活动、旅行、物体、符号七个横向图标分类。

沿用现有奶油色视觉与无依赖静态架构。分类条桌面并排，窄屏横向滚动；支持方向键、Home/End，只有当前分类内容可见。切换类别保留选择，在图标区下方持续显示当前图标；编辑旧心愿自动定位到其图标类别，未知旧图标仍可保留。

初始 JSON 增加一套化妆品、粉底、修容、提亮、眼影、眼线笔、睫毛刷，全部 food，默认不勾选。已有本机清单通过一次性版本迁移补齐，按稳定 ID 和名称去重；保留所有原心愿、勾选及历史，后续用户删除新增心愿不会被再次补回。当前 28 项加 7 项超过旧上限 32，同步将浏览器收藏、校验、抽奖和界面上限扩至 64，稠密转盘使用紧凑图标和标签。

使用原生 Emoji 与已有麦当劳 SVG，不引入远程资源或运行依赖。参考 WAI-ARIA Tabs Pattern 的键盘与语义规则，以及 Emoji Mart 的分类组织思路，独立实现。

验证：迁移幂等及数据保护、35/64 项持久化与均匀抽样、七类图标合法性及旧图标兼容；桌面和窄屏实测切换、保留选择、保存刷新和固定弹窗。
